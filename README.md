## What I'm working on

**[agent-framework](https://github.com/ckeneha1/agent-framework)** — A four-role orchestration framework (Architect → Analyst → QA → Archivist) for running multi-agent analytics workflows inside Claude Code. Hard artifact handoffs between roles. No role signs off on its own work. CI validates every role definition and template on push.

**[gatheringdata-blog](https://github.com/ckeneha1/gatheringdata-blog)** — A data science blog where I publish quantitative analyses of things worth measuring. Built on Astro + Netlify with independent Python analysis pipelines per post. Live at [gatheringdata.blog](https://gatheringdata.blog).

## How I work

I tend to find the fastest path to a business answer — whether that means challenging a stale assumption, building a scrappy tool that unblocks ten people, or reframing how a team thinks about testing entirely.

I'm skeptical of complexity for its own sake. The agent framework has four roles, not six, because presentation is inseparable from analysis and architecture belongs with the architect. The right abstraction beats the exhaustive one.
